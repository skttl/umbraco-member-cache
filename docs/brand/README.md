# Visuelt forslag til Umbraco Community MemberCache

Repositorynavnet er umbraco-member-cache. NuGet-ID, projekt og namespace er Umbraco.Community.MemberCache. Navne, ikon og palette er godkendt af brugeren den 10. november 2026. Den godkendte udformning i icon-concept.png bevares ved klargøring af de endelige ikonstørrelser.

Ikonets motiv er en medlemssilhuet kombineret med stablede kort, som repræsenterer cachede medlemsdata. Der er ingen tekst i ikonet, så det kan fungere i lille størrelse.

| Rolle | Farve | Hex |
|---|---|---|
| Base og mørk tekst | Mørk blågrøn | #142D38 |
| Primær brandfarve | Mint | #22C7A9 |
| Accent | Koral | #FF7964 |
| Lys flade | Varm elfenben | #F4F1E8 |

Palettefil: palette.svg. Farvekoderne her er de præcise brandværdier; rasterikonets pixelværdier kan variere på grund af generering og antialiasing.

Ikonet genereres med det indbyggede image_gen-værktøj. Den oprindelige genererede fil gemmes som icon-concept.png. Der er endnu ikke lavet pakning eller kontrol af en NuGet-pakkes endelige ikonstørrelse.

## Genereringsprompt

Use case: logo-brand. Create ONE polished square package icon for an open-source developer package named Umbraco.Community.MemberCache, repository umbraco-member-cache. No text or letters anywhere. The visual concept is a member profile combined with cached layers: one clear friendly geometric person silhouette (circle head and simple shoulders) on a foreground softly rounded rectangular card, with two subtly offset cards behind it suggesting stored cached copies. Make a single coherent bold symbol, not a detailed interface or illustration. Flat crisp vector-like graphic, minimal geometry, strong negative space, consistent generous corner radii, excellent legibility at 32x32 pixels. A dark deep blue-green rounded-square tile (#142D38) contains the mark. The main silhouette and foreground card accents use bright mint teal #22C7A9 and warm ivory #F4F1E8, with one very small restrained coral #FF7964 accent. Balanced centered composition, icon tile occupies about 90 percent of the square, transparent outside the rounded-square tile. No gradients, no shadows, no texture, no outlines so thin they disappear at small sizes, no lightning bolts, no database cylinder, no official Umbraco U logo, no watermarks. Output only the isolated icon, not a mockup, brand sheet, or alternatives.
